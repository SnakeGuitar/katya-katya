# Katya Katya - Requirements

## MVP Scope

### Must Have (Phase 1)
- [ ] Track character affinity per user (server persistence)
- [ ] Award coins + affinity from SinglePlayer game completion
- [ ] Display Dating Hub (character gallery with affinity progress)
- [ ] Display Character Detail (individual progress, unlock notifications)
- [ ] Persist data across sessions (server + local cache)

### Nice to Have (Phase 1)
- [ ] Animated affinity meter
- [ ] Unlock notifications/popups
- [ ] Sound effects on affinity gain

### Future Phases (Phase 2+)
- [ ] Manual clicker (tap for coins)
- [ ] Idle generation (passive income)
- [ ] Gift shop (spend coins for affinity boost)
- [ ] Dialogue/story unlocks
- [ ] Character cosmetics/upgrades
- [ ] Leaderboards (top affinities)

## Out of Scope (MVP)
- Multiplayer dating
- Real-time interaction (no turn-based dating mini-games)
- Advanced graphics/animations
- Voice acting or full dialogue trees
