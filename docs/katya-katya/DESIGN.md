# Katya Katya Visual Identity

## Brand Overview
Katya Katya is a cozy, romance-focused dating simulator with a hand-drawn aesthetic. The visual identity balances warmth (peachy pinks, warm neutrals) with playfulness, creating an inviting space for character-driven storytelling.

## Color Palette
- **Primary (Rose)**: #E7726A — warm, approachable, romantic. Used for buttons, affinity progress, character highlights.
- **Secondary (Purple)**: #6C63FF — accent color for interactive elements, dialogue choices, unlocks.
- **Neutral (Grayscale)**: For text hierarchy, backgrounds, and UI structure.

## Typography
- **Headers**: Segoe UI Bold, clean and legible
- **Body**: Segoe UI Regular, friendly and readable
- Font choices emphasize clarity without coldness — warm, inviting tone

## Spacing & Layout
- Base unit: 4px grid
- Consistent padding/margins maintain breathing room
- Mobile-first responsive design

## Visual Language
- Soft, rounded corners (8px–12px typical)
- Warm lighting in character assets
- Minimal UI chrome — focus on characters and dialogue
- Illustrations have a gentle, approachable hand-drawn feel
